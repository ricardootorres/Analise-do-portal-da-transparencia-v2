# Análise de Viagens a Serviço - Portal da Transparência 2023

Projeto de análise exploratória dos dados de viagens a serviço divulgados pelo
Portal da Transparência do Governo Federal, referentes ao ano de 2023.

## Objetivo

Responder às seguintes perguntas a partir dos dados:

1. Quais órgãos superiores mais gastam com viagens?
2. Quais os destinos mais frequentes?
3. Quais os destinos mais caros?
4. Quais os 5 cargos que mais viajam?
5. Qual a duração média das viagens?
6. Quais são os 10 cargos com mais despesas?

## Fonte dos dados

Portal da Transparência do Governo Federal — tabela de Viagens a Serviço (2023).

## Estrutura do projeto

- `data/raw`: dados brutos originais (não versionados)
- `data/processed`: dados tratados durante a análise
- `notebooks`: notebooks com a exploração e análise dos dados
- `src`: scripts auxiliares em Python
- `reports`: gráficos e materiais de apoio à apresentação final

## Tecnologias

Python, pandas, Jupyter Notebook.
